## 👨‍💻 Sobre mim

Sou estudante de **Engenharia de Software** e atuo como **Estagiário de Quality Assurance no Venturus**, garantindo a qualidade de aplicações mobile por meio de testes **manuais, exploratórios e de regressão**.

No dia a dia utilizo:

- 🔍 **ADB** para análise de logs
- 🤖 **Maestro** para automação inicial de fluxos
- 📋 **Azure Test Plans** para gestão de cenários e bugs

Minha base técnica foi construída no suporte a sistemas críticos de saúde pública (**PEC** e **SALUX**), o que desenvolveu minha visão analítica, empatia pelo usuário e rigor na documentação de falhas.

Hoje, meu foco é a **modernização da automação de testes**, com testes de API e frameworks como **Playwright** e **Cypress**.
